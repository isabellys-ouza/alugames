# AluGames

Projeto desenvolvido para praticar lógica de programação e manipulação do DOM com JavaScript.

O sistema simula o aluguel de jogos de tabuleiro, permitindo alternar o status de cada jogo entre **Alugar** e **Devolver**. Ao clicar no botão, a interface é atualizada dinamicamente, alterando o texto do botão e a aparência do card para indicar se o jogo está disponível ou alugado.

**Tecnologias utilizadas:** HTML, CSS e JavaScript.
